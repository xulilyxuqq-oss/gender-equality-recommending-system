# 课程推荐前端 Demo

这是一个不连接数据库、不调用外部大模型的静态交互 Demo。账号、画像、课程确认、推荐历史和收藏均保存在当前页面的内存中，刷新页面后重置。

## 运行

在仓库根目录执行：

~~~bash
cd demo
python3 -m http.server 4173
~~~

然后访问：

~~~text
http://127.0.0.1:4173
~~~

## 推荐体验路径

1. 点击“开始体验”；
2. 创建演示账号，或点击“使用演示账号直接进入”（预置账号 `course_demo`，密码 `demo1234`）；
3. 输入姓名；
4. 选择性别；
5. 输入“我学过 Python 入门和线性代数”；
6. 逐项确认匹配课程；
7. 确认画像并生成推荐；
8. 查看课程详情、收藏课程和推荐历史。

也可以选择“我还没有学过课程”，体验热门课程兜底结果。

画像右侧支持修改姓名、重选性别、继续添加课程和删除误选课程；历史记录支持查看当时的结果快照与软删除。退出后可在同一页面会话中重新登录，刷新页面则全部重置。

## 文件

- index.html：页面结构和无障碍语义；
- styles.css：课程排课板视觉系统与响应式布局；
- app.js：内存状态、智能体流程、课程匹配和推荐交互。
