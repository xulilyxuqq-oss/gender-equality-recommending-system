# 前端应用

这是课程推荐系统的正式前端目录。页面使用原生 HTML、CSS 和 JavaScript，通过 `/api/v1` 接口连接 `backend/`，不再在浏览器中模拟业务数据。

## 启动

先启动后端：

```bash
python3 -m uvicorn backend.app.main:app --reload --port 8000
```

再启动前端静态服务器：

```bash
cd frontend
python3 -m http.server 4173
```

访问：

- 用户端：`http://127.0.0.1:4173/`；
- 管理端：`http://127.0.0.1:4173/admin/`。

不要通过 `file://` 或双击 `index.html` 直接打开页面。正式前端使用 ES Module，并依赖正在运行的 FastAPI 接口；浏览器会阻止本地文件方式加载模块。若误用本地文件打开，页面会显示正确访问地址和启动命令。

## 说明

- 默认后端地址是 `http://127.0.0.1:8000/api/v1`；
- 用户登录令牌保存在浏览器本地存储中；管理令牌使用独立的会话存储；
- 页面支持系统深色模式和减少动态效果偏好；
- 预置账号是 `course_demo`，密码是 `demo1234`；
- 后端使用 `dataset/recommender.sqlite3`，服务重启后数据仍然保留；
- 管理端默认开发账号为 `admin` / `admin1234`，生产环境必须通过环境变量覆盖；
- 管理端包含课程库、导入、用户与画像、匹配审计、推荐运行、超参数分析、公平策略、任务、审计、系统状态和管理员管理。
